## Core UX principles

1. **Speed First:** Apprentice registration completes in under 1 minute from mobile browser.
2. **Accessible Hierarchy:** High contrast text on dark slate surfaces exceeding WCAG AA.
3. **Instant Feedback:** Spinners and badges communicate check-in state immediately.
4. **Inclusive Contingencies:** Clear 6-character code option when device camera fails.
5. **Zero Overengineering:** Streamlined forms with minimal inputs to reduce user friction.
6. **Predictable Navigation:** Consistent back buttons and role-based breadcrumbs across screens.
