# 12 — Design System

## Color palette

| Token | Hex Value | Usage |
|---|---|---|
| SENA Primary Green | `#39A900` | Primary action buttons, badges, QR borders |
| Dark Background | `#0a0f1d` | Main page background |
| Surface Card | `#0f172a` | Card panels and modal surfaces |
| Slate Border | `#1e293b` | Card dividers and table borders |
| Text Primary | `#f8fafc` | Headings and primary labels |
| Text Secondary | `#94a3b8` | Body captions and timestamps |

## Apprentice 4-tab mobile navigation

1. **Dashboard:** Active room indicator, quick check-in button.
2. **Historial:** Attendance log, validated hours, status badges.
3. **Excusas:** Justification upload, 3-business-day timer badge.
4. **Perfil:** Credentials update, Habeas Data privacy controls.

## Accessibility standards

- Text contrast ratios exceed WCAG 2.1 AA requirements (>= 4.5:1).
- Touch target sizes for mobile buttons are at least 44x44 pixels.
